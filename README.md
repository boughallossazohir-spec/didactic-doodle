# SHADOW PROTOCOL

A lightweight, standalone 2D action-platformer built with HTML, CSS, Canvas 2D, and vanilla JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern desktop browser.
3. Select **Initiate Mission**.

No external libraries, build tools, or network connection are required.

## Controls
- **A / D** or **Left / Right**: Move
- **Space**, **W**, or **Up**: Jump
- **F** or **Left Click**: Energy pulse
- **Esc**: Pause / resume

## Features
- Main menu and field manual
- Side-scrolling camera and layered sci-fi environment
- Platform movement and jumping
- Patrol sentinels with health
- Energy pulse projectiles and hit effects
- Health, signal-fragment score, extraction objective
- Pause, restart, and mission-complete states

## Performance
Uses the Canvas 2D API and vanilla JavaScript. The game is designed to run without WebGL or external assets.
