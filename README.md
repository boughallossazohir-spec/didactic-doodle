# SHADOW PROTOCOL — Wildlands

A standalone 2D adventure platformer inspired by the readable movement and exploration of classic side-scrollers, with an original world, characters, and hand-drawn-style scenery rendered procedurally in Canvas 2D.

## Run
Open `index.html` in a modern desktop browser. No install, build step, external asset, or network connection is required.

## Controls
- **A / D** or **Left / Right**: Move
- **Space**, **W**, or **Up**: Jump
- **Esc**: Pause / resume

## Gameplay
- Explore a long side-scrolling world with layered mountains, forests, ruins, platforms, and an ancient gate.
- Collect coins and glowing relics.
- Jump on roaming creatures to stun them.
- Find checkpoint flags along the route.
- Breakable-looking blocks, floating platforms, animated scenery, particles, and simple sound effects.
- Health, score, pause, restart, and world-complete states.

## Technology
Vanilla JavaScript, HTML, CSS, and Canvas 2D. Designed to remain lightweight on older computers; no WebGL or third-party libraries.
